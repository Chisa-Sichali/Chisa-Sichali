## About

I enjoy building practical systems from end to end — but for me the work starts before the code. I like to understand the problem, sketch the architecture, and make the design decisions explicit before implementing, then document the system so others can follow the reasoning.

That's why my projects ship with more than code: design docs, architecture breakdowns, and API references — the kind of artifacts that show *how* a system works, not just that it works.

- 🌱 **Learning:** scalable backend patterns, system design, AI agent integration, modern frontend workflows
- 💬 **Ask me about:** API design, backend architecture, event-driven systems, clean & maintainable code
- ⚙️ **What I value:** correctness over cleverness, simplicity over complexity, maintainability over shortcuts
